# Data

This folder holds the raw clinical tables, the notebook that turns them into a model-ready
dataset, and the resulting file.

| File | Rows × columns | Content |
|---|---|---|
| `oral_cancer_dataset.xlsx` | 2,202 × 25 | Demographics, tumour site, AJCC staging, tumour classification and treatment records. Several rows per patient. |
| `follow_up.xlsx` | 1,949 × 6 | Follow-up records: days to follow-up, disease response, timepoint category. |
| `fattori_di_rischio.xlsx` | 780 × 9 | Risk factors ("fattori di rischio"): tobacco and alcohol exposure. |
| `dataPipeline.ipynb` | – | Builds `dataset.csv` from the three tables above. |
| `dataset.csv` | 527 × 35 | One row per patient: 33 features, follow-up time and event indicator. |

The three raw tables cover the same 528 patients and are joined on `cases.case_id`. In the raw
files a missing value is written as `'--`.

## Source

All records belong to **TCGA-HNSC** (The Cancer Genome Atlas, Head and Neck Squamous Cell
Carcinoma), distributed by the U.S. National Cancer Institute through the
[GDC Data Portal](https://portal.gdc.cancer.gov/projects/TCGA-HNSC) and accessed in September 2025.
Only open-access clinical data is included: the tables contain GDC case identifiers and TCGA
barcodes, and no direct personal identifiers.

> Network: <https://www.cancer.gov/tcga>.

## From raw tables to `dataset.csv`

`dataPipeline.ipynb` runs six steps. Its paths are relative, so run it from this folder.

1. **Load** the three tables and normalise the patient identifier.
2. **Keep time-zero information only.** Rows whose `diagnoses.classification_of_tumor` is not
   `primary` (recurrences, metastases, prior, synchronous or subsequent primaries, unreported
   classifications) are discarded, so nothing recorded after the initial diagnosis reaches the
   features. The remaining rows are aggregated to one row per patient.
3. **Survival time.** The follow-up table is filtered to the `Last Contact` record of each
   patient, which gives `follow_ups.days_to_follow_up`.
4. **Risk factors.** Exposure records are reduced to one row per patient. Lifelong non-smokers
   get 0 pack-years; every other missing value stays missing and is imputed later, inside each
   model pipeline. The exposure records of the 20 patients with a smokeless-tobacco entry are
   discarded, so these patients stay in the dataset with missing exposure variables.
5. **Merge and encode** (left joins on the clinical table): binary target, one-hot and ordinal
   encodings as listed below.
6. **Clean up.** The identifier is dropped and the one patient without a follow-up time is
   removed: 528 → 527 patients.

Running the notebook with Python 3.10 and pandas 2.3 reproduces the committed `dataset.csv` byte
for byte.

## Data dictionary of `dataset.csv`

527 patients, 224 deaths (42.5%) and 303 censored observations.

| Column | Description |
|---|---|
| `follow_ups.days_to_follow_up` | Days from diagnosis to last contact or death. Range 1–6,417, median 644. |
| `demographic.vital_status_DEAD` | Event indicator: 1 = dead, 0 = alive at last contact (censored). |

### Demographics

| Column | Type | Description |
|---|---|---|
| `demographic.age_at_index` | integer | Age at diagnosis in years. Range 19–89, median 61. |
| `gender_MALE` | binary | 1 = male (385 patients), 0 = female. |
| `demographic.race_WHITE`, `demographic.race_ASIAN`, `demographic.race_NOT WHITE`, `demographic.race_Missing` | one-hot | Race in three groups plus a missing flag (451 / 11 / 50 / 15). |

### Tumour

| Column | Type | Description |
|---|---|---|
| `cases.primary_site_TONGUE` | one-hot | Tongue, including base of tongue (157). |
| `cases.primary_site_LARYNX & HYPOPHARYNX` | one-hot | Larynx or hypopharynx (127). |
| `cases.primary_site_LIP` | one-hot | Lip, including "other and ill-defined sites in lip" (73). |
| `cases.primary_site_OTHER ORAL CAVITY` | one-hot | Gum, palate, other and unspecified parts of mouth, bones (59). |
| `cases.primary_site_FLOOR OF MOUTH` | one-hot | Floor of mouth (57). |
| `cases.primary_site_OROPHARYNX & TONSIL` | one-hot | Oropharynx or tonsil (54). |
| `diagnoses.laterality_LEFT`, `diagnoses.laterality_RIGHT`, `diagnoses.laterality_MIDLINE`, `diagnoses.laterality_Missing` | one-hot | Tumour laterality plus a missing flag (145 / 168 / 34 / 180). |
| `Final_T_enc` | ordinal | T category: Tis = 0, T0 = 1, T1 = 2, T2 = 3, T3 = 4, T4 = 5, T4a = 6, T4b = 7. |

### Missing values

Two conventions coexist in `dataset.csv`, and every model notebook starts by converting the first
into the second:

- `-1` marks a missing value in the ordinal columns (`Final_N_enc`, `Final_M_enc`,
  `exposures.tobacco_smoking_status_enc`);
- an empty cell (`NaN`) marks a missing value in the three numeric exposure columns.

Random Survival Forest and DeepSurv impute with MICE fitted on the training set; XGBSE relies on
the native handling of missing values in XGBoost.
